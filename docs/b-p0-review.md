## B 与 D 的实际接口

查询取 auth 会话中的当前用户，不能把浏览器传来的作者 ID 当身份。

| 使用位置 | 调用 | 关键约定 |
|---|---|---|
| 成果列表 | listProjectDeliverables(actorId, projectId) | 服务过滤草稿隐私，返回 allowedActions |
| 成果详情 | getDeliverableDetail(actorId, projectId, id) | 返回成果、正式版本和对应历史反馈，内部请求参数不输出 |
| 创建草稿 | createDeliverableDraftAction(projectId, input) | 五个内容字段 + requestId；重复请求不重复建成果 |
| 修改草稿 | updateDeliverableDraftAction(projectId, id, input) | 五个内容字段 + expectedRevision；旧版本冲突不自动覆盖 |
| 正式提交 | submitDeliverableAction(projectId, id, input) | expectedRevision + requestId；缺少有效链接拒绝提交；每次正式提交保存快照 |
| 项目成果统计 | getProjectDeliverableStats(actorId, projectId) | 只计当前正式成果，分别为 submitted / approved / changes_requested；草稿、历史版本不进入分母 |

Action 返回 `{ok:true,data}` 或 `{ok:false,code,error}`；接口异常和网络结果不确定时保留输入，不冒充成功。类型为 report/presentation/video/survey/code/prototype/demo/other，页面用中文显示。详情时间采用北京时间。

## 数据库与部署说明

本次新增成果相关结构，拉取代码后需要升级数据库。不能只拉代码而不建表。

1. 空数据库：配置 DATABASE_URL 后运行 `npm run db:migrate`，执行 0000—0003 全链。
2. 老师原有表已存在，但没有迁移账本：只依次执行 0001、0002、0003，不能重放 0000；可使用 psql -v ON_ERROR_STOP=1 -1 -f 对每个文件执行。先在数据库副本验证和备份。
3. 已有 D P0/P1 的库：核对账本与字段，只补缺失的迁移。
4. 已有本地 P3 的库：本机已经有 D 和 P3，不要重复执行。其他成员有自己的迁移链时先合并 schema，不能覆盖 journal。

目前没有操作远程服务器数据库。正式部署仍需数据库升级、环境配置和公网验收。
