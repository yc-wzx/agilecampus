## 使用边界

- 负责人是项目分工信息，不提升团队权限。学生被指定为负责人后仍不能获得管理员的操作权限；负责人交接历史完整保存，页面显示最近 20 条。
- 当前团队成员可以登记会议和资料；创建者或团队管理员可以编辑、删除。其他团队用户不可访问，归档项目只读。
- 会议直接使用腾讯会议等现有工具，把纪要和录制链接登记回来。网站不录音、不转码、不内置网盘，也不自动抓取外部文件。外部链接仍受原平台分享权限限制。
- `.ics` 是下载时的截止日期快照，不是持续订阅或自动双向同步。只导出现有日期，全天事件按日历标准设置结束日，不制造未安排事项。
- 版本对比只读取 D 模块的正式提交快照，私有工作稿不会进入比较；不能比较两个不同成果，也不读取 PPT／PDF／视频／代码仓库内部内容。极端文本采用限时计算，超时显示整段替换。
- 原 P0–P2 的评论、公告、成果审核、迭代、通知、AI 与过程证据继续保留。本轮不修改原活动事件目录；新增会议记录没有冒充已经进入统一过程证据或自动通知。

## 接口与代码交接

业务服务仍在服务端运行，身份来自登录会话。新交互沿用 `Result<T>` 与 `UNAUTHENTICATED / FORBIDDEN / VALIDATION / CONFLICT / INTERNAL` 五种错误码；浏览器不传可信的操作人身份。

| 文件／服务 | 负责什么 |
|---|---|
| `src/lib/project-templates.ts` | 四种模板配置，前后端共用纯数据 |
| `src/lib/project.ts` 的 `createProject` | 原参数保留；可选 `templateId`、`requestId`，管理员事务创建项目和模板阶段 |
| `src/lib/project-extras.ts` | 资料增改删／分页、当前负责人和交接历史；成员、归档、版本和重复请求校验 |
| `src/app/(app)/projects/[projectId]/extras/actions.ts` | 四个对象 Action 及兼容 FormData 适配，签名见统一契约第 14 节 |
| `src/lib/project-calendar.ts` | 授权读取截止日期并生成日历 |
| `GET /api/projects/{projectId}/calendar` | 登录态下载日历；禁止共享缓存；站点链接优先使用 `AGILECAMPUS_URL`，其次 `AUTH_URL` |
| `src/lib/deliverable-comparison.ts` | 复用成果查询权限，只比较同一成果的已提交版本 |

新写入均使用请求 UUID；修改／删除资料同时传 `expectedRevision`，更换负责人传 `expectedRevision`。同键同请求安全重试，同键不同内容返回冲突；重试时重新核对当前权限，已删除资料不会被重复创建复活。保存成功自动重新读取完整页面，校验失败保留已填内容。

## 数据升级与部署

新增 `0012_p3_project_extensions.sql`，SQL、snapshot 和 journal 一起提交。新增项目模板／负责人字段，以及项目创建去重、交接历史、会议资料三张表。原项目升级后为 `blank` 模板、未指定负责人，不伪造历史。

有完整迁移账本的库运行 `npm run db:migrate`。本地已验证从 `0011` 升级到 `0012` 保留原业务，真实 `pg_dump / pg_restore` 独立恢复 18 张业务表内容一致、账本 13 条，恢复后 P3 可修改且重复迁移通过。没有迁移账本的老师旧库必须先核对基线，处理步骤见 [阿里云方案](aliyun-deployment.md)。

服务器尚未购买，本轮交付代码和部署方案。Linux 容器、HTTPS、公网访问、镜像回退、真实同学试用及真实飞书／AI 仍待实际环境；团队腾讯文档主页独立保留。
