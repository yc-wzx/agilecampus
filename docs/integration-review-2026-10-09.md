## 接口核对

- E-A01/02/03 路径 `@/lib/activity`、参数、分页/coverage 保留；覆盖正确性与事件接入在模块内部修复。
- F-N01/02/05 固定入口 `@/lib/notification`；F-N03/04 固定 `@/app/(app)/notifications/actions`。首参 actorId 为服务端绑定，不允许浏览器伪造。
- F 返回固定 `PageResult<NotificationItem>`、`{count,asOf}`、`{id,readAt}`、`{markedCount,asOf}`、`{createdCount}`；类型附加到公共契约，不改原有业务字段。
- Action 统一 Result 与五种错误码；旧任务/Agent API 返回值保留兼容，不要求其他同学重写。
- D 仍只有一个 dispatcher 与组合 sink；任务/迭代活动和通知与业务同事务，成果 outbox 重投按事件键去重。
- 通知已读不改变任务状态，也不消除 A 的待修改成果。站内消息与原飞书通知分开，外部凭据未配不冒充送达。
